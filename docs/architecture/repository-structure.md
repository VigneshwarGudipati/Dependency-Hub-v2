### Frontend Rules
- **One API client**: All API calls go through `src/services/apiClient.ts`
- **No hardcoded backend URLs**: Use `VITE_API_BASE_URL` env var
- **SSR-safe**: No direct `window`/`document` access outside `typeof window !== "undefined"` guards
- **No mock data in core pages**: dashboard, repositories, vulnerabilities, packages, graph all use `apiClient`
- **Deferred features use mockService/mockData honestly**: scanner, audit-logs, reports, system-health, users are clearly fixtures

### Backend Rules
- **PYTHONPATH="backend"** must be set for all pytest and uvicorn commands
- **Migrations run from `database/` directory** with Alembic
- **env.py always overrides alembic.ini sqlalchemy.url** from `.env` at runtime
- **No business logic in route handlers** — routes delegate to services
- **No database queries in Pydantic schemas**
- **Test suites are strictly separated** to avoid module collisions:
  - Run DB tests: `pytest -v tests`
  - Run API tests: `pytest -v backend/tests`

| Registry integration | `database/backend/app/integrations/registry/` |
